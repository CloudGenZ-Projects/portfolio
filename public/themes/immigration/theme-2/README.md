# immigration-1

Static Canadian & US Immigration Law Firm Website (Theme 1 - Motivus Law).

100% static frontend cloned from https://motivus.law/ with all HTML, CSS styles, Webflow/Lenis smooth scrolling, custom web fonts (Alexandria & Open Sans), and high-resolution media assets (AVIF/WebP/SVG) fully localized.

## Features
- **Modern Responsive Design**: Exact layout, typography, and responsive breakpoints from Motivus Law.
- **Fluid Lenis Animations**: Smooth Lenis scroll engine and Webflow micro-interactions.
- **Zero External Dependencies**: All fonts, images, and scripts are stored locally offline.
- **Clean In-Page Anchors**: Navigation links connect cleanly to sections on the homepage without 404s.

## Local Preview
Run the included multi-threaded Python server:
```bash
python server.py 8080
```
Then visit: `http://localhost:8080`

## Deployment
- **Vercel**: Import repository -> Framework Preset: **Other** -> Deploy!
- **Netlify**: Drag and drop folder or connect repo.
- **Apache/cPanel**: Upload files directly to `public_html`.
