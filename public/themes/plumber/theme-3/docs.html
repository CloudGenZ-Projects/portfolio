1. Getting Started (Installation)

Thank you for purchasing HouzFix! To install the theme on your WordPress site, follow these instructions to ensure your plumbing website gets off to a perfect start.

Uploading via WordPress Admin

1. Navigate to Appearance > Themes.
2. Click Add New and hit the Upload Theme button.
3. Choose the houzfix.zip file you downloaded from ThemeForest.
4. Click Install Now and wait for the success message, then click Activate.

Installing Required Plugins

Once activated, you will see a prompt to install required plugins (like Elementor and our Plumbing Core features plugin). Click Begin installing plugins and activate them.
